# 场景专属材料（不随发布基线交付）

本目录存放 **SPN 跨城专线投诉联创场景**的专属材料，记录了该场景对接过程中沉淀的
业务流程、调用链路、接入步骤与踩坑经验。它们不属于 `main` 发布分支的通用文档基线，
只在 `dev` 分支保留，供真实对接该场景的集成方查阅。

通用能力文档请看上一级目录（API 参考 / 设计 / 集成指南 / 回调契约 / 开发指南），
东信指令平台转发适配见 `docs/zh/指令平台适配指南.md`。

| 文档 | 内容 |
|---|---|
| `业务流.md` | 跨城专线投诉场景的四类 A2A-T 接口业务流程定义 |
| `SpringSpnDemo调用链路.md` | Demo 端到端调用链路逐步说明（含时序与日志对照） |
| `集成方场景接入指南.md` | 面向该场景集成方的详细接入步骤与现场经验（1089 行，含大量踩坑记录） |
| `A2AT-SDK-DEPENDENCY.md` | A2A-T SDK 版本演进与依赖关系的场景快照 |
| `工作台AgentScope结合方案.md` | 工作台与 AgentScope 结合的设想稿（尚未落地，仅作参考） |

> 注意：这些材料使用场景专属术语（工作台、OMC、WAIMO、两地市等），与通用文档的
> 「宿主智能体 / 被调度智能体」术语体系不同，属预期行为。
